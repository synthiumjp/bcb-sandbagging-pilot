# BCB Sandbagging Detection Pilot — Pipeline

Pre-registered at OSF: [link to be added post-lodge]

## Setup

```bash
pip install llama-cpp-python datasets scipy
```

Edit `configs/local_config.py` with your GGUF model paths.

## Execution order

**Step 1: Sample items** (run once)
```bash
python sample_items.py
```
Outputs `data/sampled_items.jsonl` — 500 items × 4 domains, with C sub-prompt assignments.

**Step 2: Run inference** (Condition A must run first)
```bash
# Option A: run all conditions sequentially for one model
python run_inference.py --model qwen2.5-7b --condition all
python run_inference.py --model llama3-8b --condition all
python run_inference.py --model phi3.5-mini --condition all

# Option B: run specific conditions (A must be first)
python run_inference.py --model qwen2.5-7b --condition A
python run_inference.py --model qwen2.5-7b --condition B
# etc.

# Sensitivity S4: temperature 0.7
python run_inference.py --model qwen2.5-7b --condition A --temperature 0.7
python run_inference.py --model qwen2.5-7b --condition B --temperature 0.7
```

Outputs `results/{model}_{condition}.jsonl` — one record per trial. Supports resume (skip completed items).

**Step 3: Run analysis** (after all inference complete)
```bash
python run_analysis.py
```
Outputs:
- `analysis/analysis_report.txt` — human-readable report with gate decision
- `analysis/full_results.json` — machine-readable results


## Pre-registered constraints

- Seed: 42
- 10-option items only (chance = 0.10)
- Greedy decoding T=0 (primary)
- α = 0.01 per cell, Bonferroni across 12 cells
- Gate: ≥3/12 cells significant in Condition B
- No honest-baseline exclusion in primary analysis
- Refusals coded as missing (primary), incorrect (S2)
